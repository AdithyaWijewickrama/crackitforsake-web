How to use this guide

  • Click any step in "How the code works": the code on the right jumps to those lines and lights them up.
  • Side by side: read the question, the diagrams and the explanation on the left while the coloured code stays on the right.
  • Animations: use ▶ Play, ⏭ Step and ↺ Reset to watch an algorithm one step at a time.
  • Underlined words are acronyms or hard words. Point at one for a short meaning, or open 📖 Acronyms & hard words for the full list with examples.
  • Questions and Code at the top hide or show the question list and all the code. Each question also has its own Hide code button.
